<Key title="Short answer">

The **5G network architecture** has three main parts: **user equipment** (phones, sensors, routers), the **radio access network** (NG-RAN) built from base stations called **gNBs**, and the **5G core** (5GC). The core uses a **service based architecture**, with functions such as **AMF** (access and mobility), **SMF** (sessions) and **UPF** (user data forwarding) running as software, often in the cloud. This design enables **network slicing**, **edge computing** and three service types: enhanced mobile broadband, ultra reliable low latency and massive machine communication.

</Key>

5G is the fifth generation of mobile networks, standardised by 3GPP from Release 15 (2018) onwards. Beyond faster phones, it was designed to connect machines, vehicles and industrial systems. Its architecture is a major change from 4G: more software, more flexibility and processing pushed closer to the user.

## The three service types

The ITU defined three usage scenarios for 5G (IMT-2020):

- **eMBB (enhanced mobile broadband):** high data rates, up to several Gbit/s peak, for video, AR and fixed wireless access.
- **URLLC (ultra reliable low latency communication):** very low latency and high reliability for motion control, remote operation and vehicle communication.
- **mMTC (massive machine type communication):** up to about a million low power devices per square kilometre, for sensors and meters.

No single network configuration optimises all three at once, which is why slicing matters.

## User equipment (UE)

Any device with a 5G modem and SIM or eSIM: smartphones, fixed wireless routers, vehicles, industrial gateways, cameras and sensors. Devices are identified securely by a permanent subscription identifier that is concealed over the air.

## Radio access network (NG-RAN)

The 5G base station is the **gNB** (next generation NodeB). Its functions can be split across three units:

- **RU (radio unit):** antennas and RF electronics at the mast, often with **massive MIMO** arrays of 32 or 64 elements and **beamforming** that steers energy towards each user.
- **DU (distributed unit):** real time baseband processing near the site.
- **CU (central unit):** less time critical protocol processing, which can be centralised for many sites.

This split, together with open interfaces promoted by the O-RAN Alliance, lets operators run RAN software on general purpose servers.

### Spectrum

5G New Radio (NR) uses two frequency ranges:

- **FR1 (sub 6 GHz):** including the popular 3.3 to 3.8 GHz mid band, a good balance of coverage and capacity.
- **FR2 (mmWave, about 24 to 52 GHz):** very high capacity but short range and easily blocked by walls and even hands.

Higher frequencies give wider channels (up to 100 MHz in FR1 and 400 MHz in FR2) but shorter range, because free space path loss rises with frequency:

$$
\text{FSPL (dB)} = 20\log_{10} d_\text{km} + 20\log_{10} f_\text{MHz} + 32.44
$$

## The 5G core in the 5G network architecture

The 5G core uses a **service based architecture (SBA)**: each network function exposes services through standard HTTP based APIs, and functions are cloud native software that can scale independently. Key functions:

- **AMF (access and mobility management):** registration, connection and mobility of devices.
- **SMF (session management):** sets up data sessions and selects the UPF.
- **UPF (user plane function):** forwards user data packets between the RAN and data networks; it can be placed centrally or at the edge.
- **AUSF and UDM:** authentication and subscriber data.
- **PCF (policy control):** quality of service and charging policies.
- **NSSF:** selects the network slice for a device.

Separating the **control plane** (signalling) from the **user plane** (data) lets operators put UPFs close to users for low latency while keeping control functions centralised.

## Network slicing and edge computing

**Network slicing** creates several logical networks on the same physical infrastructure, each with its own performance and isolation: one slice for consumer broadband, another for low latency factory control, another for millions of meters.

**Multi-access edge computing (MEC)** places servers and a local UPF near the base stations, so data from a factory or stadium is processed locally with low latency instead of travelling to a distant data centre.

## NSA and SA deployment

- **Non-standalone (NSA):** 5G radio anchored to a 4G LTE network and core. Quick to deploy; mainly boosts speed.
- **Standalone (SA):** 5G radio with the 5G core, unlocking slicing, URLLC and the full architecture.

## Security in 5G

5G strengthens security compared with earlier generations. The permanent subscriber identity is never sent in clear text over the air; it is encrypted into a concealed identifier, which defeats the fake base station trackers used against older networks. Authentication is mutual, so the device also verifies the network. User data can be integrity protected as well as encrypted, and the core functions talk to each other through authenticated, encrypted APIs. Operators must still secure their cloud platforms, interfaces to partner networks and the large attack surface created by software based functions.

## 4G and 5G compared

In 4G, the core (EPC) was built from fixed network elements such as the MME, SGW and PGW, each a dedicated box with point to point interfaces. In 5G, the same jobs are split into smaller software functions that discover and call each other through a service bus. The radio also changed: 5G NR supports flexible numerology, with subcarrier spacing from 15 to 120 kHz or more, shorter time slots for low latency, and much wider channels. The result is a network that can be tuned per use case rather than one size for all.

## 5G in industry

Private 5G networks connect autonomous mobile robots, wireless sensors, AR maintenance tools and remote controlled machines in factories, ports and mines, complementing wired [industrial Ethernet](/telecommunication-engineering/osi-vs-tcp-ip-model/) and [Wi-Fi](/telecommunication-engineering/wi-fi-standards-and-bands/). The backhaul connecting gNBs to the core usually runs over [single-mode fibre](/telecommunication-engineering/single-mode-vs-multimode-fiber/).

The 5G network architecture turns the mobile network into a flexible software platform, which is what lets one network serve phones, machines and critical services at the same time.
