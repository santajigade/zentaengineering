<Key title="Short answer">

A **VLAN** (virtual local area network) splits one physical switched network into separate logical networks, each its own broadcast domain. Switches mark frames with an IEEE 802.1Q tag carrying a 12 bit VLAN ID. Access ports carry one untagged VLAN, trunk ports carry many tagged VLANs, and routers connect different VLANs.

</Key>

Without a VLAN, every device connected to a group of switches is in one broadcast domain: a broadcast from any computer reaches all the others. As networks grow, this wastes bandwidth and mixes traffic that should be kept apart, such as office PCs, IP phones, cameras and building controllers. VLANs solve this in software, letting engineers group ports by function rather than by physical location.

## What a VLAN does

A VLAN is a group of switch ports, and the devices on them, that behave as if they were on their own separate switch. A switch only forwards frames between ports in the same VLAN. Benefits include:

- **Smaller broadcast domains:** broadcasts such as ARP requests stay within one VLAN.
- **Security and segmentation:** sensitive systems are separated, and traffic between VLANs passes through a router or firewall where it can be filtered.
- **Flexibility:** a user can move desks and stay in the same VLAN by changing one port setting.
- **Traffic separation and priority:** voice, video and control traffic can be placed in their own VLANs and given quality of service treatment.

Switching and routing roles are compared in [router vs switch](/telecommunication-engineering/router-vs-switch/). VLANs work at the data link layer (Layer 2) of the [OSI model](/telecommunication-engineering/osi-vs-tcp-ip-model/).

When frames for several VLANs share one link, the receiving switch must know which VLAN each frame belongs to. IEEE 802.1Q inserts a **4 byte tag** after the source MAC address:

- **TPID (16 bits):** the value 0x8100, which identifies the frame as tagged.
- **PCP (3 bits):** priority code point, a class of service from 0 to 7 used for quality of service.
- **DEI (1 bit):** drop eligible indicator, marking frames that may be dropped first under congestion.
- **VID (12 bits):** the VLAN identifier. Values 0 and 4095 are reserved, so VLAN IDs 1 to 4094 are usable.

The tag raises the maximum Ethernet frame size from 1518 to 1522 bytes. The switch adds the tag when a frame enters a trunk and removes it before delivering the frame to an end device on an access port, so ordinary computers never see it.

$$
N_\text{VLAN} = 2^{12} - 2 = 4094
$$

## Access, trunk and native VLAN ports

- **Access port:** belongs to one VLAN and carries untagged frames. Used for PCs, printers and most end devices.
- **Trunk port:** carries frames for many VLANs, each tagged with its VLAN ID. Used between switches, and between a switch and a router, firewall or server that supports tagging.
- **Native VLAN:** the one VLAN on a trunk whose frames are sent untagged. On Cisco switches it is VLAN 1 by default. Both ends of a trunk must agree on it.

## Types of VLAN

- **Default VLAN:** VLAN 1 on most switches; all ports start in it and it cannot be deleted.
- **Data (user) VLAN:** carries normal user traffic, often one per department or function.
- **Voice VLAN:** carries IP phone traffic. A phone and a PC can share one port, with the phone tagging its own traffic in the voice VLAN and the PC using the untagged data VLAN.
- **Management VLAN:** used to reach switch management interfaces, kept separate from user traffic.
- **Native VLAN:** the untagged VLAN on a trunk, best set to an unused VLAN rather than VLAN 1.

VLAN membership is usually **static**, set per port. **Dynamic** assignment by MAC address or by IEEE 802.1X authentication places a device in a VLAN based on who it is.

## Inter-VLAN routing

Because each VLAN is a separate broadcast domain, normally with its own [IP subnet](/telecommunication-engineering/ip-addressing-and-subnetting/), traffic between VLANs must be routed:

- **Router on a stick:** one physical router interface connects to a switch trunk and is split into subinterfaces, one per VLAN, each with its own IP address as the default gateway.
- **Layer 3 switch:** a switched virtual interface (SVI) is created for each VLAN and the switch routes between them at hardware speed. This is the usual method in modern networks.

A [firewall](/telecommunication-engineering/firewalls-explained/) can also act as the gateway for sensitive VLANs so that traffic between them is inspected.

## VLAN configuration basics

The example below uses Cisco IOS commands; other vendors use similar concepts with different syntax.

```text
! Create VLANs
vlan 10
 name SALES
vlan 20
 name ENGINEERING
! Access port for a PC in VLAN 10
interface GigabitEthernet0/1
 switchport mode access
 switchport access vlan 10
! Trunk to the next switch
interface GigabitEthernet0/24
 switchport mode trunk
 switchport trunk allowed vlan 10,20
 switchport trunk native vlan 999
```

Check the result with `show vlan brief` and `show interfaces trunk`. Good practice is to allow only the VLANs that are needed on each trunk, disable automatic trunk negotiation on access ports, shut down unused ports and place them in an unused VLAN.

## Key formulas for VLAN

| Quantity | Formula | Symbols and units |
| --- | --- | --- |
| Usable VLAN IDs | N = 2¹² − 2 = 4094 | 12 bit VID; 0 and 4095 reserved |
| Priority levels | 2³ = 8 | 3 bit PCP, values 0 to 7 |
| Maximum tagged frame | 14 + 4 + 1500 + 4 = 1522 | bytes: header, tag, payload, FCS |
| Tag overhead | 4 ÷ frame size | Fraction of frame length |

## Beyond 4094 VLANs

Service providers and large data centres can run out of 4094 VLAN IDs. **IEEE 802.1ad (Q-in-Q)** adds an outer service tag, with TPID 0x88A8, around the customer tag. **VXLAN**, defined in RFC 7348, carries Layer 2 frames inside UDP packets with a 24 bit network identifier, giving about 16 million segments across routed data centre networks.

## VLAN interview and viva questions

1. **What is a VLAN?** It is a logical group of switch ports that forms its own broadcast domain, separate from other VLANs on the same physical switches.
2. **How many VLANs can 802.1Q support and why?** 4094, because the VLAN ID field is 12 bits (4096 values) and the values 0 and 4095 are reserved.
3. **What is the difference between an access port and a trunk port?** An access port carries untagged frames for one VLAN; a trunk port carries tagged frames for many VLANs.
4. **What is the native VLAN?** It is the VLAN whose frames cross a trunk without a tag; both ends must use the same native VLAN.
5. **How do devices in different VLANs communicate?** Through inter-VLAN routing, using a router on a stick with subinterfaces or a Layer 3 switch with one SVI per VLAN.
