<Key title="Short answer">

**How large language models work:** a large language model (LLM) is a very large **transformer** neural network trained to predict the **next token** in text. Tokens become vectors, pass through stacked **attention** layers and produce a probability for every possible next token. One token is chosen, appended and the loop repeats. Pre-training, fine-tuning and human feedback shape its behaviour.

</Key>

Large language models write text, answer questions, summarise documents, translate languages and generate code. They can seem mysterious, but the core loop is simple: read the text so far, predict what comes next, repeat. This article explains each stage in plain terms.

## How large language models work, step 1: tokens

The model does not see letters or words directly. A tokenizer splits text into **tokens**, usually subword pieces, and each token is mapped to an ID and then to an **embedding** vector. Position information is added so the model knows the order of tokens. This is covered in detail in [tokenization and embeddings](/ai-data-engineering/tokenization-and-embeddings/).

## Step 2: the transformer and attention

The transformer architecture, introduced by Vaswani and colleagues in 2017, is a stack of identical layers. Each layer has two main parts:

- **Self-attention:** for every token, the model computes how relevant every earlier token is and mixes their information accordingly. In "The valve on the pump was leaking, so the technician replaced it", attention helps "it" connect to "valve".
- **Feedforward network:** a small [neural network](/ai-data-engineering/how-neural-networks-work/) applied to each token, which transforms and stores much of the model's learned knowledge.

Inside attention, each token produces three vectors: a **query** (what am I looking for?), a **key** (what do I contain?) and a **value** (what information do I pass on?). The scores are:

$$
\text{Attention}(Q, K, V) = \text{softmax}\!\left(\frac{QK^\top}{\sqrt{d_k}}\right)V
$$

Many attention "heads" run in parallel, each free to track different relationships such as grammar, references or topic. Stacking dozens of layers lets the model build very abstract representations.

## Step 3: predicting the next token

After the last layer, the model produces a score for every token in its vocabulary, often 50 000 to over 200 000 entries. A **softmax** turns these scores into probabilities. One token is chosen, appended to the text, and the whole sequence goes through the model again to predict the following token. This one token at a time process is called **autoregressive generation**.

How the token is chosen is controlled by **sampling settings**:

- **Greedy:** always pick the most likely token. Predictable but can be repetitive.
- **Temperature:** divides the scores before softmax. Low temperature sharpens the distribution (focused output); high temperature flattens it (more varied, more creative, more error prone).
- **Top-k and top-p (nucleus) sampling:** only sample from the most likely tokens, cutting off the long tail of unlikely ones.

## Step 4: training

### Pre-training

The model starts with random weights and reads a huge corpus of text: web pages, books, code and articles, often trillions of tokens. For each position it predicts the next token, the error is measured with cross-entropy loss, and backpropagation adjusts billions of weights. This is **self-supervised learning**: the text provides its own labels, so no manual labelling is needed. Research on scaling laws found that performance improves predictably with more parameters, data and compute.

Through this simple task, the model learns grammar, facts, reasoning patterns and styles, because predicting text well requires them.

### Fine-tuning and alignment

A pre-trained model continues text, but does not reliably follow instructions. Further training shapes it into an assistant:

- **Supervised fine-tuning:** train on examples of good instruction and response pairs.
- **Reinforcement learning from human feedback (RLHF):** people rank alternative responses; a reward model learns their preferences, and the LLM is optimised to produce preferred answers. Related methods use AI feedback or direct preference optimisation.
- **Safety training:** teaches the model to decline harmful requests and to be honest about uncertainty.

## What LLMs can and cannot do

**Strengths:** drafting and editing text, summarising, translation, answering questions, explaining concepts, writing and reviewing code, extracting structured data from documents.

**Limitations:**

- **Hallucination:** confident but false statements, because the model predicts plausible text rather than looking up facts.
- **Knowledge cutoff:** the model knows only what was in its training data unless given tools or documents.
- **Context limits:** text beyond the context window is not seen.
- **Arithmetic and exact logic** can be unreliable without tools such as a calculator or code execution.
- **Bias** from the training data can appear in outputs.

## Using LLMs in engineering work

- **Retrieval augmented generation (RAG):** search a document store with embeddings and give the relevant passages to the model, so answers are grounded in your manuals, standards and procedures.
- **Tool use:** let the model call calculators, databases or APIs for exact results.
- **Prompting:** state the task, context, format and constraints clearly; give examples.
- **Human review:** always check outputs used for safety, design or compliance decisions.

LLMs are a powerful layer on top of the [machine learning](/ai-data-engineering/supervised-vs-unsupervised-learning/) fundamentals. Knowing that they are next token predictors, trained on text and shaped by feedback, explains both their impressive abilities and their characteristic mistakes.

## Key formulas for how large language models work

| Quantity | Formula | Symbols and units |
| --- | --- | --- |
| Scaled dot product attention | Attention(Q, K, V) = softmax(QKᵀ ÷ √d_k) V | Q = query, K = key, V = value matrices; d_k = key vector dimension (dimensionless) |
| Next token probability with temperature | P_i = e^(z_i ÷ T) ÷ Σ e^(z_j ÷ T) | z_i = logit (raw score) of token i, T = temperature (dimensionless), sum over all candidate tokens |

## How large language models work: interview and viva questions

1. **What does a large language model actually predict?** It predicts a probability for every token in its vocabulary as the next token. One token is chosen, appended to the text and the whole sequence is fed back in, which is called autoregressive generation.
2. **What are the query, key and value vectors in attention?** The query says what a token is looking for, the key says what each token contains and the value carries the information passed on. Attention scores come from query and key dot products, scaled and passed through softmax.
3. **How does temperature change the output?** Temperature divides the logits before softmax. A low temperature sharpens the distribution for focused output, and a high temperature flattens it for more varied but more error prone text.
4. **Why is pre-training called self-supervised learning?** The text supplies its own labels, because the target at each position is simply the next token, so no manual labelling is needed.
5. **Why do LLMs hallucinate?** They generate the most plausible continuation of the text rather than looking up facts, so a fluent but false answer can still be likely. Retrieval augmented generation, tools and human review reduce the problem.
