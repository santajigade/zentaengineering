<Key title="Short answer">

**Supervised vs unsupervised learning** differ in the training data. Supervised learning uses labelled examples, where each input has a known correct output, and learns to predict it for new inputs through classification or regression. Unsupervised learning uses unlabelled data and finds hidden structure on its own, such as clusters, reduced dimensions or anomalies.

</Key>

Machine learning lets computers learn patterns from data instead of following hand written rules. The first question in any machine learning project is what kind of learning the problem calls for, and that depends mainly on whether you have examples of the right answer. This article compares the two most common approaches with algorithms, examples and practical tips.

## Supervised learning

In supervised learning, every training example has an input x (features) and a target y (label). The algorithm learns a function f that maps x to y as accurately as possible, then applies f to new, unseen inputs.

There are two main tasks:

- **Classification:** the target is a category. Is this email spam? Which of five fault types is this motor showing? Is the part good or defective?
- **Regression:** the target is a number. What will this house sell for? What is the remaining useful life of this bearing? What will tomorrow's energy demand be?

A simple linear regression model, for example, predicts:

$$
\hat{y} = w_1 x_1 + w_2 x_2 + \dots + w_n x_n + b
$$

and training chooses the weights w and bias b that minimise the error between predictions and true labels, often the mean squared error.

Common supervised algorithms include linear and logistic regression, decision trees, random forests, gradient boosted trees, support vector machines, k-nearest neighbours and neural networks.

Performance is measured on data the model has not seen: accuracy, precision, recall and F1 score for classification; mean absolute error and root mean squared error for regression.

## Unsupervised learning

In unsupervised learning, there is only x. The algorithm looks for structure such as groups, directions of variation or unusual points.

- **Clustering:** group similar items, for example customer segments, document topics or operating modes of a machine. Algorithms include k-means, hierarchical clustering, DBSCAN and Gaussian mixture models.
- **Dimensionality reduction:** compress many features into a few that keep most of the information, for visualisation or as input to other models. Principal component analysis (PCA), t-SNE and UMAP are common.
- **Anomaly detection:** find points that do not fit the normal pattern, such as fraudulent transactions or abnormal sensor readings. Isolation forests and autoencoders are widely used.
- **Association rules:** find items that occur together, such as products bought in the same basket.

Evaluation is harder because there is no correct answer to compare with. Engineers use internal measures, such as how compact and separated clusters are, and, most importantly, whether the result is useful to domain experts.

## Supervised vs unsupervised learning: comparison

| Feature | Supervised learning | Unsupervised learning |
| --- | --- | --- |
| Training data | Labelled (input and correct output) | Unlabelled (input only) |
| Goal | Predict a known target | Discover structure or patterns |
| Main tasks | Classification, regression | Clustering, dimensionality reduction, anomaly detection |
| Evaluation | Compare predictions with true labels | Indirect measures and expert judgement |
| Data preparation cost | High if labels must be created | Lower; no labelling needed |
| Typical algorithms | Linear and logistic regression, random forest, gradient boosting, neural networks | k-means, DBSCAN, PCA, isolation forest, autoencoders |
| Example | Predict whether a pump will fail within 30 days | Find unusual operating patterns in pump data |

## Key formulas for supervised vs unsupervised learning

| Quantity | Formula | Symbols and units |
| --- | --- | --- |
| Linear regression prediction | ŷ = w₁x₁ + w₂x₂ + ... + wₙxₙ + b | x = features, w = weights, b = bias |
| Mean squared error | MSE = (1/N) Σ (y_i − ŷ_i)² | y = true label, ŷ = prediction, N = number of examples |
| Precision | P = TP ÷ (TP + FP) | TP = true positives, FP = false positives |
| Recall | R = TP ÷ (TP + FN) | FN = false negatives |
| F1 score | F1 = 2PR ÷ (P + R) | harmonic mean of precision and recall |
| k-means objective | J = Σ_k Σ_(x in cluster k) ‖x − μ_k‖² | μ_k = centroid of cluster k; minimised by k-means |

## Other learning paradigms

- **Semi-supervised learning:** a little labelled data plus a lot of unlabelled data.
- **Self-supervised learning:** the data provides its own labels, for example predicting a hidden word from its context. It is how [large language models](/ai-data-engineering/how-large-language-models-work/) are pre-trained.
- **Reinforcement learning:** an agent learns from rewards by interacting with an environment, used in robotics, games and control.

## How to choose

1. **Do you have a clear target and labelled examples?** Use supervised learning.
2. **Is labelling too expensive or is the question exploratory?** Start with unsupervised learning to understand the data.
3. **Do you need to find rare, unknown events?** Unsupervised anomaly detection is often the first step.
4. **Do you have little labelled data but much unlabelled?** Consider semi-supervised or self-supervised methods.

Many real systems combine both: clustering to define groups, then supervised models within each group, or PCA to reduce features before a classifier.

## Practical tips

- Split data into training, validation and test sets, and keep the test set untouched until the end.
- Avoid data leakage: never let information from the future or from the target sneak into the features.
- Scale features for distance based methods such as k-means and k-nearest neighbours.
- Start with simple models as baselines before trying complex ones such as [neural networks](/ai-data-engineering/how-neural-networks-work/).
- Follow a disciplined [data science workflow](/ai-data-engineering/data-science-workflow/) from problem definition to deployment.

Supervised and unsupervised learning are the foundation of nearly all practical machine learning, from image recognition in [computer vision](/ai-data-engineering/classification-vs-detection-vs-segmentation/) to monitoring industrial equipment.

## Supervised vs unsupervised learning interview and viva questions

1. **What is the key difference between supervised and unsupervised learning?** Supervised learning trains on inputs paired with known correct outputs, while unsupervised learning has only inputs and must find structure such as groups or unusual points by itself.
2. **What is the difference between classification and regression?** Both are supervised tasks. Classification predicts a category, such as spam or not spam, and regression predicts a number, such as a price or remaining useful life.
3. **Why is evaluating an unsupervised model harder?** There is no correct answer to compare with, so engineers rely on internal measures such as cluster compactness and separation, and on whether domain experts find the result useful.
4. **Why should features be scaled before k-means?** k-means uses distances between points, so a feature with a large numeric range would dominate the distance and the clustering unless all features are put on a similar scale.
5. **What is data leakage?** It is when information from the future or from the target itself enters the features, which makes the model look accurate in testing but fail in real use.
